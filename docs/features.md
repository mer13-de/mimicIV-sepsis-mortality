# Признаки основной модели

Перечень 85 признаков, поданных в модель LightGBM. Все признаки рассчитываются только по данным, доступным к моменту T0 (для лабораторных показателей — по времени готовности результата). Итоговый перечень формируется автоматически на этапе 6 (`data/stage6_features.json`): признаки с долей пропусков более 90% в обучающей выборке исключаются. Точные определения, коды `itemid` и правила очистки — в комментариях к соответствующим этапам.
Категориальные признаки: `admission_group`, `careunit_group`, `resp_support_t0`.
